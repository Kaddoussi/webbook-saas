WebBook Agent API

Embed the agent in your stack.

REST + webhooks. Send a manuscript, an outline, or a single prompt. Get back a live, multilingual, narrated WebBook URL — and event streams as the agent reasons.

  • POST /v1/webbooks
    Create a WebBook from a brief, file, or URL.
  • PATCH /v1/webbooks/:id
    Edit a chapter — agent re-renders, re-translates, re-narrates.
  • GET /v1/webbooks/:id/stream
    SSE stream of agent reasoning, plans, and ships.
  • GET /v1/webbooks/:id/insights
    Reader questions, drop-offs, popular chapters.
